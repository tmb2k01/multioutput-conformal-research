Calibration sample size with fixed predictions

Standard conformal only · 24 November 2026

Findings

Every case has the same realized correctness pattern for every seed and split; mean joint top-1 accuracy is 80.04%. All comparisons use standard split conformal with the product score. No method or case was chosen using test results.

Nested calibration budgets: at 90% nominal coverage, mean set sizes span 65.17–81.42, covered information spans 0.65–1.64 bits, and mean absolute class coverage gaps span 2.51–4.58 percentage points.

The identical probability arrays and test examples were verified across all budgets. With 100 calibration examples the across-seed set-size SD is 37.92; with 12,000 it is 1.24. This comparison isolates calibration sampling variability from model quality.

Smaller sets are useful only together with coverage. Covered information assigns zero to empty sets and to sets missing the truth, so an aggressive rule cannot appear informative merely by returning empty or incorrect singleton sets.

Design and metrics

Hold every probability vector and test example fixed; calibrate on nested prefixes of the same 12,000-example calibration pool. This separates calibration variability from model quality.

One YAML defines this entire group: shared base settings, blocks, their fixed settings, and all cases. There are 5 cases, 5 seeds (42, 43, 44, 45, 46), 30,000 examples per seed, 132 joint labels, and alpha levels 0.05, 0.1, 0.15, 0.2, 0.25. Comparisons are paired by seed; whiskers are seed ranges; tables show mean ± sample SD. Neither is a confidence interval.

Efficiency is mean joint prediction-set size (lower is better at comparable coverage). Information per nonempty set is log2(number of candidates / set size); empty sets receive zero. Mean covered information also assigns zero when the true joint label is missing. This measures combinatorial candidate reduction under a uniform candidate reference, not posterior entropy or calibrated uncertainty. Singleton, correct-singleton, empty, full-set and nonempty non-full-set rates are exported at every alpha.

Class coverage gap averages abs(per-class coverage − nominal coverage) across classes. Undercoverage gaps and worst-class coverage are exported as well. Standard conformal guarantees joint marginal coverage under exchangeability, not within every class.

Calibration budgets use nested prefixes of the same shuffled calibration pool. The cached pool and test arrays are identical in every case. Prediction diagnostics describe the full cached pool; n_calibration records the actual prefix used to compute the threshold.

Interpretation and limits

These are synthetic experiments with 5 seeds. Ranges and SDs are descriptive; no significance test or universal monotonic relationship is claimed.

Expected top-1 accuracy is 80%. Shared correctness across heads is kept fixed. The 80% coverage target lies near the mixture boundary between correct and wrong score components, so thresholds and set sizes can be sensitive to seed there.

Study the group-specific control alongside the main contrasts. Population overall coverage can remain close to nominal while some classes are undercovered. Per-class estimates still contain finite-test noise; observed-class gaps omit unobserved classes.
